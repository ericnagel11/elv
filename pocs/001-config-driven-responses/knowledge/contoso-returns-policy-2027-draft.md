# Contoso Retail: Returns and Refunds Policy (2027 revision)

Document owner: Customer Experience
Effective date: 2027-01-01
Supersedes: Returns and Refunds Policy effective 2026-03-01

This revision replaces the return window, the return shipping fee, and the
refund timing rules of the previous policy. All other returns rules carry
forward unchanged.

## Standard return window

Most items may be returned within 45 days of delivery for a full refund,
provided they are unused and in their original packaging. The 45 day return
window runs from the delivery date shown in order tracking, not the order date.

Contoso Rewards members receive an extended 90 day return window on the same
terms.

## Return shipping fee

Returns carry no return shipping fee. There is no fee deducted from the refund.
Every return ships free using a prepaid return label generated in the customer's
account, whether the return is customer-initiated, an exchange, or caused by a
Contoso error.

## Refund timing

Refunds for orders under 75 are issued as soon as the carrier scans the return,
with no inspection. Larger orders are inspected within 3 business days of
arrival at the returns center.

## Opened personal care products

Opened personal care and grooming products may be returned within 45 days under
the Contoso satisfaction guarantee, limited to two such returns per customer per
year.
