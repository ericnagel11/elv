- Contoso Care Plus: never translate. Always written exactly as "Contoso Care Plus".
- Contoso One: never translate. Never "Contoso Eins".
- Rückgabe: use for a voluntary commercial return.
- Widerruf: use only for the statutory right of withdrawal. Never use these two
  interchangeably, because they carry different deadlines and different obligations.
- Erstattung: use for a refund. Do not use "Rückerstattung".
- Bestellnummer: use for an order reference. Do not use "Auftragsnummer".
- Versanddienstleister: use for a carrier. Do not use "Spediteur" for parcel delivery.
