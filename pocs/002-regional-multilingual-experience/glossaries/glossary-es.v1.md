- Contoso Care Plus: never translate. Always written exactly as "Contoso Care Plus".
- Contoso One: never translate. Never "Contoso Uno".
- Devolución: use for a return of goods.
- Reembolso: use for a refund. Do not use "devolución del dinero".
- Número de pedido: use for an order reference. Do not use "número de orden".
- Paquetería: use for a carrier. Do not use "transportista".
- Use "usted" throughout. Never "vos". Never "vosotros".
